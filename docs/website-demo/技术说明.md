# 让技术文档，也好读

用清晰的结构，说明复杂的事情。

## 一次文档交付

| 阶段 | 要做的事 | 产出 |
| --- | --- | --- |
| 整理 | 汇总资料与要点 | 提纲 |
| 写作 | 补充表格与示例 | 初稿 |
| 交付 | 检查格式并导出 | 文档 |

## 把过程画出来

```mermaid
flowchart LR
    A[整理资料] --> B[编写内容]
    B --> C[检查预览]
    C --> D[导出文档]
```
