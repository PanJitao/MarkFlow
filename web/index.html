功能

熟悉的操作，专注的写作。

写作与预览

  • 源码与预览并排，边写边看。
  • 两侧都能选中文字，通过右键调整加粗、斜体、删除线、颜色与高亮。

文件与命令

  • 从左侧文件树打开、管理本地文档，用查找和自动保存延续工作。
  • 命令面板快速定位操作；快捷键遵循 Windows Ctrl 与 macOS Cmd 的习惯。

内容与排版

  • 用表格、代码高亮与 Mermaid 图表，把想法写清楚。
  • 文档在本地编辑与转换，无需账号即可开始。

实际界面

按你的方式工作。

MarkFlow 0.4.5 实际界面，点击可放大。

01 / 外观

字体、颜色与背景，随你调整。

主题、文件树字体与字号、源码和预览字体、颜色、背景、透明度与玻璃效果，都在同一处调整。

壁纸可以使用本地图片、视频，也可以读取 Wallpaper Engine 壁纸库与壁纸自带参数。

壁纸支持范围

入口在“设置 → 主题与外观”。选择 Wallpaper Engine 壁纸会清空并替换本地背景；网页与场景效果取决于素材和平台兼容性。

02 / 转换

把已有文档带进 Markdown。

导入 Word、Excel、PowerPoint、文本型 PDF、HTML、ODF、RTF、EPUB、CSV；需要交付时导出 Word 或 HTML，PDF 通过系统打印。

转换支持范围

上述格式导入为 Markdown，Word 与 HTML 支持导出，PDF 通过系统打印。复杂版式可能变化；扫描件需先用其他工具完成 OCR。

03 / 桌面伙伴

便签与提醒，有自己的样子。

内置蓝发角色与动作来自 dsh-pet，作者 PC2005-cloud，采用 MIT 许可。可以导入图片、动画、精灵图或宠物包，并调整大小、透明度、镜像、速度、气泡颜色和问候语。

便签和待办可提前 15、30、60 分钟或自定义时间提醒，由宠物气泡提示。收起主窗口后仍会运行；需要彻底退出时使用宠物菜单。
