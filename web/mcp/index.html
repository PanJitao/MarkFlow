MarkFlow Pet MCP · 0.4.5

让 AI 为你
制作桌面宠物。

把角色描述交给支持本机 stdio 的外部 AI。它读取运行时规范，使用自己的绘图或动画工具制作素材，再通过 MarkFlow 校验、安装并显示新的桌面宠物。

连接前准备

运行 MarkFlow，复制软件中的 MCP 配置，加入支持本机 stdio 的 AI 客户端。生成素材使用该客户端的绘图或视频工具。

接入步骤

从本机连接到第一只宠物。

需要 MarkFlow、一个支持本机 stdio 的 AI 客户端，以及该客户端可用的图像或视频生成工具。

  1. 01

    开启宠物 MCP

    运行包含宠物 MCP 的 0.4.5 版本，进入 设置 → 主题与外观 → 宠物样式与 AI 接入，开启“允许 MCP 控制宠物”，并复制界面生成的连接配置。

    Windows 0.4.5 正式版包含此功能；macOS 0.4.5 为预览构建，尚未完成签名、公证与真机验证。

  2. 02

    加入本机 stdio 配置

    在支持本机 stdio 的 AI 客户端中加入配置。使用软件界面生成的真实可执行文件路径与参数，不要自行猜测路径；保持 MarkFlow 运行。

    连接与权限只在客户端完成，网页不能代替你连接本机。

  3. 03

    生成、校验并安装

    复制上方指令，发送给具备图像或视频生成能力的外部 AI。它会按规范准备素材、校验宠物包、安装，再切换新角色并显示宠物。

    MCP 不生成图片，也不需要填写模型密钥。生成能力来自外部 AI 已连接的工具。

运行时工具

AI 可以调用哪些能力。

工具由 AI 客户端调用，格式以本机返回的规范为准。

  • pet_get_schema

    读取包格式、参数与模板。

  • pet_prepare_generation

    返回外部绘图或视频工具需要的制作规范，不生成像素。

  • pet_list

    列出已安装角色与保存参数。

  • pet_get_state

    查询当前角色、可用动作与最新命令状态。

  • pet_validate_pack

    校验本地宠物包及其素材，不安装。

  • pet_install_pack

    安装已校验的本地包，不覆盖已有 id。

  • pet_create_from_image

    从本地图片或精灵图创建并安装宠物包。

  • pet_configure

    调整大小、透明度、镜像、速度、气泡和问候语等参数。

  • pet_show

    显示宠物，不收起编辑器。

  • pet_play

    播放当前角色实际支持的动作。

  • pet_say

    显示文字气泡，可同时指定动作。

高级规范与限制

连接与执行

  • 仅支持本机 stdio MCP。使用界面生成的真实可执行文件路径、--pet-mcp 与 --data-dir 参数，不要猜测路径。
  • 网页 URL 是文档，不是公网 MCP 端点。访问页面不能连接本机。
  • 除 pet_get_schema 和 pet_prepare_generation 外，其余工具需要 MarkFlow 正在运行且 MCP 开关已开启。
  • 请求在空闲时执行，30 秒后过期；连续请求会替换尚未执行的请求。
  • 便签提醒和宠物拖动优先于 AI 动作。
  • queued 只表示请求已入队，不代表动画已经播放完成。

素材与边界

  • MCP 不生成图片或视频，不调用模型，不需要在 MarkFlow 内填写模型密钥。
  • 单个素材文件最大 64 MB；整个宠物包最大 256 MB。
  • 单张静态图片只显示静态角色，不会自动成为多帧动画。
  • GIF 与 WebP 保留素材自身速度；速度参数用于视频和精灵图。
  • 缺少标准动作会回退到 idle；播放前先查询角色实际支持的动作。
  • MCP 不开放编辑器文档、便签或待办内容。从宠物菜单彻底退出后，AI 无法继续控制。
  • 素材需要真实作者与授权说明，不应为未知授权素材编造许可证。
